### TC-MTS-031 Преподавателя назначили → добавлен ведущим на вебинар

- Приоритет: high   Тип: api   Роли: manager, teacher
- Предусловия: Мероприятие «МТС Линк» со статусом «Успешно»
- Требование: часть 4, 15_часть_4_синхронизация_лекторов.md, раздел «Флоу»
| Шаг | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Назначить преподавателя на мероприятие | Запускается сверка состава лекторов |

### TC-MTS-033 Ошибка по одному лектору не блокирует остальных
- Автотест: tests/api/mts_link/test_lecturers.py::TestLecturers::test_lecturer_error_for_one_does_not_block_others
- Приоритет: medium   Тип: api   Роли: manager
- Предусловия: Мок отвечает отказом по одному из назначенных преподавателей
- Требование: часть 4, 15_часть_4_синхронизация_лекторов.md, раздел «Поведение при ошибке»
| Шаг | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Назначить двух преподавателей, один — «проблемный» по моку | Второй преподаватель успешно добавлен на вебинар |
| 2 | Проверить статус части | «Ошибка интеграции», у проблемного преподавателя нет ссылки входа |
