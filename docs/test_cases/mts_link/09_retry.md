### TC-MTS-055 Кнопка «Повторить» видна только при ошибке
- Автотест: tests/ui/mts_link/test_retry.py::TestRetry::test_retry_button_visible_only_on_error
- Приоритет: high   Тип: ui   Роли: manager
- Предусловия: Два мероприятия — одно со статусом «Ошибка» по части, другое «Успешно»
- Требование: часть 8, 19_часть_8_ручной_перезапуск_синхронизации.md, раздел «Флоу»
| Шаг | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Открыть карточку мероприятия со статусом «Ошибка» по части | У этой части в блоке статусов есть кнопка «Повторить» |
| 2 | Открыть карточку мероприятия со статусом «Успешно» | Кнопки «Повторить» нет ни у одной части |

### TC-MTS-056 Перезапуск конкретной части запускает синхронизацию только её
- Автотест: tests/ui/mts_link/test_retry.py::TestRetry::test_retry_specific_part_syncs_only_that_part
- Приоритет: high   Тип: ui   Роли: manager
- Предусловия: Часть «Файлы презентаций» в статусе «Ошибка», остальные — «Успешно»
- Требование: часть 8, 19_часть_8_ручной_перезапуск_синхронизации.md, раздел «Флоу»
| Шаг | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Нажать «Повторить» у части «Файлы презентаций» | Статус этой части переходит в «В процессе», затем «Успешно» |
| 2 | Проверить request_log_audit | Новые запросы только по файлам, не по участникам/лекторам/данным вебинара |

### TC-MTS-057 Перезапуск создания вебинара тянет всю цепочку
- Автотест: tests/ui/mts_link/test_retry.py::TestRetry::test_retry_creation_triggers_full_chain
- Приоритет: high   Тип: ui   Роли: manager
- Предусловия: Часть «Создание вебинара» в статусе «Ошибка», остальные части не запущены
- Требование: часть 8, 19_часть_8_ручной_перезапуск_синхронизации.md, раздел «Повтор создания вебинара»
| Шаг | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Нажать «Повторить» у части «Создание вебинара» | Статус части переходит в «Успешно», id вебинара и сессии сохранены |
| 2 | Проверить остальные части | Синхронизация данных, участников, лекторов и файлов запускается автоматически следом |

### TC-MTS-058 При идущем авторетрае повторный ручной запуск не создаётся

- Требование: часть 8, 19_часть_8_ручной_перезапуск_синхронизации.md, раздел «Соотношение с автоматическими ретраями»
