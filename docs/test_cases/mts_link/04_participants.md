### TC-MTS-029 Ошибка регистрации одного слушателя не блокирует остальных
- Автотест: tests/api/mts_link/test_participants.py::TestParticipants::test_registration_error_for_one_does_not_block_others
- Приоритет: medium   Тип: api   Роли: manager
- Предусловия: Мок отвечает отказом по конкретному слушателю (объекту), остальные — успех
- Требование: часть 3, 14_часть_3_синхронизация_участников.md, раздел «Поведение при ошибке»
| Шаг | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Запустить сверку состава с одним «проблемным» слушателем | Остальные слушатели зарегистрированы успешно |
| 2 | Проверить статус части | «Ошибка интеграции» (часть слушателей не зарегистрирована), у проблемного слушателя нет персональной ссылки |

### TC-MTS-030 Повторная сверка добивает незарегистрированных
