02.11.2026 кейсы и `test_trajectory.py` были удалены: опирались на несуществующий
`/individual-trajectory/assignments/{id}/mts-link`. 10.11.2026 восстановлены на реальном контракте (живая разведка
на mts-link-release-main): мероприятие «МТС Линк» в ИТ — офлайн-контент пользователя, `POST /users/content/offline`
(`data.user_ids` + `attributes` как у schedule-item), список и статус — `GET /users/content/offline/user-content/{user_id}`
(`attributes.url`, `attributes.mts_link`, `attributes.is_registered`), снятие — `DELETE /users/content/offline/detach-activities` с `data.attributes.user_ids` + `content_ids` (так делает админка; маршрут `DELETE /users/content/offline/{id}` фронт не использует, он отвечает 404).
В админке: карточка пользователя → «Назначения» → «Индивидуальная траектория обучения» → вкладка «Очные».
Стенд — реальный прод-аккаунт МТС Линк (лектор Вера, дата завтра, имена с «[ТЕСТ]»), см. 16_prod_safe_run.md.
TC-MTS-079 требует проведённого эфира с ведущим — ручной шаг ПМИ, без автотеста.

### TC-MTS-076 Назначение в ИТ создаёт отдельный вебинар
- Автотест: tests/api/mts_link/test_trajectory.py::TestTrajectory::test_it_assignment_creates_dedicated_webinar
- Приоритет: high   Тип: api   Роли: manager
- Предусловия: Есть потоковое мероприятие «МТС Линк» (для сравнения) со статусом синхронизации «Успешно»; есть слушатель
- Требование: часть 14, 25_часть_14_вебинар_в_индивидуальной_траектории.md, раздел «Флоу»
| Шаг | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Назначить мероприятие «МТС Линк» слушателю в индивидуальной траектории (карточка пользователя → Назначения → ИТ → Очные) | Мероприятие появилось в ИТ слушателя с типом «МТС Линк» |
| 2 | Дождаться синхронизации (блок «Интеграция» / `attributes.mts_link.webinar_status`) | `webinar_status = synced`, появилась ссылка на вебинар |
| 3 | Сравнить с потоковым мероприятием | У назначения свой `mts_webinar_id` и своя ссылка, не совпадающие с потоковым вебинаром |

### TC-MTS-077 На вебинар в ИТ регистрируется только этот слушатель
- Автотест: tests/api/mts_link/test_trajectory.py::TestTrajectory::test_it_webinar_has_single_registered_listener
- Приоритет: medium   Тип: api   Роли: manager
- Предусловия: Вебинар под назначение в ИТ создан; есть второй слушатель без этого назначения
- Требование: часть 14, 25_часть_14_вебинар_в_индивидуальной_траектории.md, раздел «Отличия от потокового сценария»
| Шаг | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Дождаться сверки участников назначения | `participants_sync_status = success` |
| 2 | Открыть мероприятие в ИТ слушателя A | Мероприятие на месте, тип «МТС Линк»; `is_registered` остаётся `false` — это отметка регистрации/посещения в ЛМС, а не участие в МТС Линк (участники сверяются без неё) |
| 3 | Открыть ИТ слушателя B | Мероприятия там нет; в кабинете МТС Линк у вебинара один участник (ручная сверка, API детализации не даёт) |

### TC-MTS-078 Снятие назначения до вебинара удаляет его целиком
- Автотест: tests/api/mts_link/test_trajectory.py::TestTrajectory::test_removing_it_assignment_before_webinar_deletes_it
- Приоритет: high   Тип: api   Роли: manager
- Предусловия: Назначение в ИТ с созданным, ещё не проведённым вебинаром (дата в будущем)
- Требование: часть 14, 25_часть_14_вебинар_в_индивидуальной_траектории.md, раздел «Снятие назначения»
| Шаг | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Снять мероприятие с индивидуальной траектории слушателя (админка → ИТ → Очные → удалить; `DELETE /users/content/offline/detach-activities`, `user_ids` + `content_ids`) | Ответ 200, мероприятие сразу пропало из ИТ слушателя |
| 2 | Проверить МТС Линк (кабинет / `external_requests_audit`: `DELETE …/eventsessions/{id}`) | Вебинар и сессия удалены целиком; в `mts_webinars` у записи заполнен `deleted_at` (ручная сверка, в автотесте только шаг 1) |
