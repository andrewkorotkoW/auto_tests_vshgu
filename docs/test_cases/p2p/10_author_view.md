# Тест-кейсы: 10. Вид автора работы

| Параметр | Значение |
|---|---|
| Область | tests/ui/p2p (расширение practical_task_page.py — результат по своей работе) |
| Стенд | develop (см. README §13) |
| Роли | user |

Кейсы описывают целевое поведение по приоритетной версии (04 → 02, `docs/requirements/tz2026/README.md`).
Вид автора не входит в перечень категорий Этапа 1, отмеченных для автоматизации, — автотест не планируется.

- Приоритет: high   Тип: manual   Роли: user
- Предусловия: -
- Test IT: 2d7439c7-d272-4ecd-8139-d5e9f69e297f
| Шаг | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Сдать работу по P2P-ПЗ и открыть её карточку на разных этапах (сдано, на взаимопроверке, завершена, итог выставлен) | На каждом этапе автору виден актуальный статус работы |
