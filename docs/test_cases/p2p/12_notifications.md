# Тест-кейсы: p2p / уведомления

| Параметр | Значение |
|---|---|
| Область | ручная проверка UI-уведомлений слушателям (без автотеста на Этапе 1) |
| Стенд | develop (см. README §13) |
| Роли | user, external |

Краткое ТЗ п.1.1.3.5: уведомления через UI слушателям потока, по иным каналам — сторонним
пользователям (04 §12). Все кейсы ручные, `- Автотест:` не пишется.

### TC-P2P-082 Слушатель потока получает UI-уведомление о назначенной ему на проверку работе
- Требование: 04 §12, краткое ТЗ п.1.1.3.5
- Приоритет: high   Тип: manual   Роли: user
- Предусловия: -
| Шаг | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Назначить слушателю чужую работу на peer-проверку (вручную или автоматически) | Назначение создано |
| 2 | Авторизоваться этим слушателем | В UI отображается уведомление о доступной для проверки работе |

### TC-P2P-083 Повторное уведомление слушателю-проверяющему после возврата работы на доработку
- Требование: 04 §12
- Приоритет: medium   Тип: manual   Роли: user
- Предусловия: Открытый вопрос вне списка 05 (см. 04 §12)
| Шаг | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Работа, которую проверял слушатель, возвращена на доработку и отправлена повторно | Работа снова доступна для переоценки |
| 2 | Проверить, приходит ли слушателю-проверяющему повторное UI-уведомление | Подтверждение заказчиком не получено |

### TC-P2P-084 Внешние неавторизованные проверяющие не получают уведомлений через UI (вариант первого этапа)
- Требование: 05 §15
- Приоритет: medium   Тип: manual   Роли: external
- Предусловия: -
| Шаг | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Добавить внешнего проверяющего к ПЗ | Внешний проверяющий создан |
| 2 | Проверить отсутствие внутрисистемных UI-уведомлений для внешнего проверяющего | Уведомлений нет — ссылка передаётся администратором вне системы (предложенный вариант первого этапа) |

### TC-P2P-085 Канал и события email-уведомления внешнему проверяющему
- Требование: 04 §7, §12
- Приоритет: low   Тип: manual   Роли: admin, external
- Предусловия: Ждёт ответа заказчика: вопрос №15 (05_вопросы_заказчику_16)
| Шаг | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Добавить внешнего проверяющего с email | Внешний проверяющий создан |
| 2 | Проверить, отправляется ли email и по каким событиям | Определяется ответом заказчика на вопрос №15 |
