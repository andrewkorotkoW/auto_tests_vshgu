Кейсы описывают целевое поведение по приоритетной версии (04 → 05, `docs/requirements/tz2026/README.md`).
Гистограммы по критериям одиночного/множественного выбора в отчёте — ручные кейсы (без автотеста).

### TC-P2P-049 Среднее арифметическое по числовому критерию считается с округлением до 0,1
- Требование: 04 §5.1, 05 §1
- Автотест: tests/api/p2p/test_aggregation.py::TestAggregation::test_numeric_criterion_average_rounded_to_one_decimal
- Приоритет: high   Тип: api   Роли: reviewer
- Предусловия: По работе получено несколько peer-проверок по числовому критерию (шкала)
| Шаг | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Получить по критерию оценки 4, 5, 4 от трёх проверяющих | Оценки сохранены |
| 2 | Прочитать агрегированное значение по критерию | Показано среднее арифметическое с округлением до одного знака: 4,3 |
