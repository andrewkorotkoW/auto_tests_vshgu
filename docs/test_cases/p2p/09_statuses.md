# Тест-кейсы: 09. Статусы работы и проверки

| Параметр | Значение |
|---|---|
| Область | tests/api/p2p (статусная модель по 03 §8) |
| Стенд | develop (см. README §13) |
| Роли | admin, reviewer, user |

Статусная модель — 03 §8 (04 §10 подтверждает верхнеуровневый список статусов работы, без деталей
по статусам назначенной проверки). Максимально переиспользуются существующие статусы ПЗ; новые
статусы вводятся только если текущих недостаточно (04 §10).

### TC-P2P-062 Статус работы «Не сдано» → «Сдано» после отправки ответа слушателем
- Требование: 03 §8.2 п.1–2
- Автотест: tests/api/p2p/test_statuses.py::TestStatuses::test_work_status_not_submitted_to_submitted
- Приоритет: high   Тип: api   Роли: user
- Предусловия: -
| Шаг | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Проверить статус работы до отправки ответа | Статус «Не сдано» |
| 2 | Слушатель отправляет ответ по P2P-ПЗ | Статус меняется на «Сдано» |

### TC-P2P-063 Статус работы «Сдано» → «На взаимопроверке» после назначения проверяющих
- Требование: 03 §8.2 п.3
- Автотест: tests/api/p2p/test_statuses.py::TestStatuses::test_work_status_submitted_to_under_review
- Приоритет: high   Тип: api   Роли: admin
- Предусловия: Работа в статусе «Сдано»
| Шаг | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Назначить работу слушателям-проверяющим и/или штатным проверяющим | Назначения созданы |
| 2 | Проверить статус работы | Статус «На взаимопроверке» |

### TC-P2P-064 Статус работы меняется на «Взаимопроверка завершена, ожидает итогового результата» после набора минимума
- Требование: 03 §8.2 п.4
- Автотест: tests/api/p2p/test_statuses.py::TestStatuses::test_work_status_review_completed_awaiting_final_result
- Приоритет: high   Тип: api   Роли: admin
- Предусловия: По работе набрано минимальное количество peer-проверок
| Шаг | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Получить по работе минимально необходимое количество peer-проверок | Проверки сохранены |
| 2 | Проверить статус работы | Статус «Взаимопроверка завершена, ожидает итогового результата»; слушатели-проверяющие больше не получают работу на проверку |

### TC-P2P-065 Статус работы меняется на «Итоговый результат выставлен» после действия штатного проверяющего
- Требование: 03 §8.2 п.5
- Автотест: tests/api/p2p/test_statuses.py::TestStatuses::test_work_status_final_result_set
- Приоритет: high   Тип: api   Роли: reviewer
- Предусловия: Работа в статусе «Взаимопроверка завершена, ожидает итогового результата»
| Шаг | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Штатный проверяющий выставляет итоговый результат | Результат сохранён |
| 2 | Проверить статус работы | Статус «Итоговый результат выставлен» |

### TC-P2P-066 Статус работы «Возвращено на доработку» и возврат в цикл проверки после повторной сдачи
- Требование: 03 §8.2 п.6
- Автотест: tests/api/p2p/test_statuses.py::TestStatuses::test_work_status_returned_for_revision_and_resubmission
- Приоритет: high   Тип: api   Роли: reviewer, user
- Предусловия: -
| Шаг | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Штатный проверяющий возвращает работу на доработку | Статус «Возвращено на доработку» |
| 2 | Автор отправляет новую версию работы | Работа снова переходит в цикл проверки (статус «На взаимопроверке» или аналогичный) |

### TC-P2P-067 Статус назначенной проверки «Назначена» → «В работе» → «Проверена»

- Автотест: tests/api/p2p/test_statuses.py::TestStatuses::test_review_status_assigned_in_progress_reviewed
- Приоритет: high   Тип: api   Роли: user
- Предусловия: -
| Шаг | Действие | Ожидаемый результат |
|---|---|---|

### TC-P2P-070 Нужен ли отдельный статус «Взаимопроверка завершена, ожидает итогового результата»
- Требование: 04 §10.2
- Приоритет: low   Тип: manual   Роли: admin
- Предусловия: Ждёт ответа заказчика: вопрос №8 (05_вопросы_заказчику_16)
| Шаг | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Довести работу до набора минимального количества peer-проверок | Минимум набран |
| 2 | Проверить, вводится ли отдельный промежуточный статус или штатный проверяющий может выставить итог без него | Определяется ответом заказчика на вопрос №8 |
