# Тест-кейсы: 13. Сертификаты

| Параметр | Значение |
|---|---|
| Область | ручная проверка сертификатов за проверку (без автотеста на Этапе 1) |
| Стенд | develop (см. README §13) |
| Роли | user, reviewer, external |

Краткое ТЗ п.1.1.1.4/1.1.2.3, детализация — 03 §14. Все кейсы ручные, `- Автотест:` не пишется.

### TC-P2P-086 Сертификат за проверку выдаётся после выполнения всего назначенного объёма проверок в рамках одного ПЗ
- Требование: 03 §14.1
- Приоритет: high   Тип: manual   Роли: user
- Предусловия: Слушателю назначено проверить N чужих работ
| Шаг | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Слушателю назначено проверить N работ | Назначения созданы |
| 2 | Слушатель проверяет N-1 работу | Сертификат ещё не выдан |
| 3 | Слушатель проверяет последнюю, N-ю работу | Сертификат за проверку выдан |

### TC-P2P-087 Внешние неавторизованные проверяющие сертификат за проверку не получают
- Требование: 03 §14.2
- Приоритет: medium   Тип: manual   Роли: external
- Предусловия: -
| Шаг | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Внешний проверяющий проверяет по ссылке все доступные ему работы | Проверки сохранены |
| 2 | Проверить выдачу сертификата | Сертификат внешнему проверяющему не выдаётся |

### TC-P2P-088 Прогресс «Проверено X из K»: где показывать
- Требование: 04 §13
- Приоритет: medium   Тип: manual   Роли: user
- Предусловия: Ждёт ответа заказчика: вопрос №11 (05_вопросы_заказчику_16) — предложенный вариант: краткий прогресс в общем списке ПЗ, подробный — внутри ПЗ
| Шаг | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Слушателю назначено несколько работ на проверку, часть уже проверена | Прогресс «Проверено X из K» |
| 2 | Проверить отображение прогресса в общем списке ПЗ и внутри конкретного ПЗ | Место и детализация показа определяются ответом заказчика на вопрос №11 |

### TC-P2P-089 Прогресс до сертификата считается отдельно по каждому ПЗ/потоку или суммарно
- Требование: 04 §13
- Приоритет: low   Тип: manual   Роли: user
- Предусловия: Ждёт ответа заказчика: вопрос №11 (05_вопросы_заказчику_16)
| Шаг | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Пользователь участвует в нескольких P2P-ПЗ/потоках одновременно | Несколько назначений на проверку |
| 2 | Проверить, считается ли прогресс отдельно по каждому ПЗ в каждом потоке или суммарно | Определяется ответом заказчика на вопрос №11 |

### TC-P2P-090 Получают ли сертификат штатные проверяющие ПЗ; нужен ли сертификат внешнему проверяющему
- Требование: 04 §13
- Приоритет: low   Тип: manual   Роли: reviewer, external
- Предусловия: Открытый вопрос вне списка 05 (см. 04 §13, частично перекликается с вопросом №11)
| Шаг | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Штатный проверяющий ПЗ выполняет назначенные проверки | Проверки выполнены |
| 2 | Проверить выдачу сертификата штатному проверяющему и (отдельно) внешнему проверяющему | Правила выдачи не подтверждены заказчиком |
