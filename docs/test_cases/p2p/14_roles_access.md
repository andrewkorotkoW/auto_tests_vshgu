# Тест-кейсы: 14. Роли и доступ

| Параметр | Значение |
|---|---|
| Область | матрица ролей по 04 §3 (без автотеста на Этапе 1) |
| Стенд | develop (см. README §13) |
| Роли | admin, reviewer, user, external |

Матрица ролей — 04 §3; ограничение по групповым ПЗ — 02 п.4 (не из ТЗ, зафиксировано как отдельное
ограничение по итогам обсуждения). Роли не входят в перечень категорий Этапа 1 для автоматизации.

### TC-P2P-091 Администратор/адм. организации/поддержка/менеджер видят всё, но не выставляют итог без назначения проверяющим
- Требование: 04 §3
- Приоритет: high   Тип: manual   Роли: admin
- Предусловия: -
| Шаг | Действие | Ожидаемый результат |
|---|---|---|
| 1 | От имени администратора (не назначенного проверяющим ПЗ) открыть список работ потока | Видны все работы, назначения, внешние ссылки, статусы, результаты по критериям, статистика и отчёты |
| 2 | Попытаться выставить итоговый результат | Действие недоступно — нужно назначение проверяющим ПЗ |

### TC-P2P-092 Штатный проверяющий видит все работы по ПЗ и может выставлять/менять итог
- Требование: 04 §3
- Приоритет: high   Тип: manual   Роли: reviewer
- Предусловия: -
| Шаг | Действие | Ожидаемый результат |
|---|---|---|
| 1 | От имени штатного проверяющего открыть список работ по назначенному ПЗ | Видны работы, файлы, все peer-проверки, агрегаты, комментарии |
| 2 | Вернуть работу на доработку и выставить/изменить итоговый результат | Оба действия доступны |

### TC-P2P-093 Роль «Преподаватель» — системная, не даёт права проверяющего по конкретному ПЗ
- Требование: 04 §3.1
- Приоритет: medium   Тип: manual   Роли: admin
- Предусловия: -
| Шаг | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Выдать пользователю роль «Преподаватель», не назначая его проверяющим ни одного ПЗ | Роль выдана |
| 2 | Проверить доступ пользователя к работам конкретного P2P-ПЗ | Доступа к проверке конкретного ПЗ нет — роль даёт только доступ к интерфейсу проверки в целом |

### TC-P2P-094 Слушатель-проверяющий видит только назначенные чужие работы, не выставляет итог
- Требование: 04 §3
- Приоритет: high   Тип: manual   Роли: user
- Предусловия: -
| Шаг | Действие | Ожидаемый результат |
|---|---|---|
| 1 | От имени слушателя-проверяющего открыть список доступных работ | Видны только назначенные ему чужие работы |
| 2 | Проверить наличие действия выставления итогового результата | Действие недоступно |

### TC-P2P-095 Внешний неавторизованный проверяющий видит список всех сданных работ ПЗ в потоке по ссылке, без ЛК
- Требование: 04 §3, §7
- Приоритет: high   Тип: manual   Роли: external
- Предусловия: -
| Шаг | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Перейти по персональной ссылке внешнего проверяющего | Открывается список всех сданных работ ПЗ в потоке |
| 2 | Проверить отсутствие личного кабинета, статистики и отчёта | Ничего из этого не доступно |

### TC-P2P-096 Автор работы видит статус, итоговую оценку и значения по критериям своей работы
- Требование: 04 §3
- Приоритет: high   Тип: manual   Роли: user
- Предусловия: -
| Шаг | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Автор открывает карточку своей работы после выставления итогового результата | Виден статус, одна итоговая оценка и значения по всем критериям |

### TC-P2P-097 Групповые практические задания недоступны для режима взаимопроверки
- Требование: 02 п.4 (не из краткого ТЗ, ограничение по итогам обсуждения)
- Приоритет: high   Тип: manual   Роли: admin
- Предусловия: -
| Шаг | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Открыть карточку группового ПЗ | Карточка открыта |
| 2 | Попытаться включить «Включить взаимопроверку» для группового ПЗ | Настройка недоступна/отклонена — групповые ПЗ проверяются по стандартному сценарию |
