Кейсы описывают целевое поведение по приоритетной версии (04 → 03, `docs/requirements/tz2026/README.md`).
Известное расхождение версий (README): право итогового результата — 04: любой штатный проверяющий

Кейсы 043–046 написаны по приоритетной версии 04 (без отдельного признака).
