|---|---|

Кейсы описывают целевое поведение по приоритетной версии (04 → 03, `docs/requirements/tz2026/README.md`).

(`tests/ui/practical_tasks/test_review_practical_task.py`) — образец структуры, не менялись.

### TC-P2P-028 Слушателю-проверяющему показываются только чужие работы, собственная — не выводится
- Требование: 04 §3.1, §6.1
- Автотест: tests/ui/p2p/test_peer_review.py::TestPeerReview::test_peer_reviewer_sees_only_others_works
- Приоритет: high   Тип: ui   Роли: user
- Предусловия: -
| Шаг | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Авторизоваться слушателем, у которого есть и собственная сданная работа, и назначенные чужие | Список открыт |
| 2 | Открыть список работ на проверку | В списке только чужие назначенные работы, собственная работа отсутствует |
