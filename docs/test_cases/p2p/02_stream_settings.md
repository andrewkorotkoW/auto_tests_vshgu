# Тест-кейсы: p2p / настройки ПЗ в потоке

| Параметр | Значение |
|---|---|
| Область | tests/api/p2p, tests/ui/p2p (назначение ПЗ в поток) |
| Стенд | develop (см. README §13) |

Кейсы описывают целевое поведение по приоритетной версии (04 → 03, `docs/requirements/tz2026/README.md`).

### TC-P2P-015 В потоке задаётся список участников взаимопроверки из слушателей этого потока
- Требование: 04 §2, 03 §5.1
- Автотест: tests/api/p2p/test_stream_settings.py::TestStreamSettings::test_p2p_participants_limited_to_stream_listeners
- Приоритет: high   Тип: api   Роли: admin
- Предусловия: -
| Шаг | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Назначить P2P-ПЗ в поток и указать список участников взаимопроверки | В список можно добавить только слушателей этого потока |

### TC-P2P-018 Настройка «Количество работ для проверки одним слушателем» в автоматическом режиме

### TC-P2P-020 Поведение системы, если к установленному сроку работа не набрала минимум peer-проверок
- Требование: 04 §2, §10.1
- Приоритет: medium   Тип: manual   Роли: admin
- Предусловия: Ждёт ответа заказчика: вопрос №3 (05_вопросы_заказчику_16)
| Шаг | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Настроить срок взаимопроверки в потоке короче, чем требуется для набора минимума проверок | Срок настроен |
| 2 | Дождаться истечения срока с недобором проверок | Поведение системы определяется ответом заказчика на вопрос №3 (сейчас не зафиксировано) |
