# Тест-кейсы: 05. Внешний проверяющий по ссылке

| Параметр | Значение |
|---|---|
| Область | tests/api/p2p, tests/ui/p2p (новая страница external_review_page.py — без авторизации, новый browser context) |
| Стенд | develop (см. README §13) |
| Роли | admin, external |

Кейсы описывают целевое поведение по приоритетной версии (04 → 03/05, `docs/requirements/tz2026/README.md`).
Известное расхождение версий (README): 04 — внешний видит список всех сданных работ ПЗ в потоке,
ссылка многоразовая; 03/05 — видит только одну работу, ссылка одноразовая на пару «работа —
проверяющий». Кейсы 033–039 написаны по приоритетной версии 04.
