- Приоритет: high   Тип: api   Роли: admin, user
- Предусловия: -
- Test IT: 5ed3ec90-b603-45e4-8779-ca839cef117f
| Шаг | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Подготовить поток с несколькими сданными работами | Работы сданы |
| 2 | Назначить слушателю на проверку конкретную чужую работу вручную | Назначение создано, работа появляется в списке слушателя-проверяющего |
