### TC-TICKETS-012 Пользователь создаёт обращение через форму, видит его в списке и своё сообщение в переписке
<!-- steps-hash: b3947e54017f -->
- Автотест: tests/ui/tickets/user/test_user_creates_ticket.py::TestUserCreatesTicket::test_user_creates_ticket_and_sees_it
- Приоритет: high   Тип: ui   Роли: user
- Предусловия: Список обращений подгружается постранично и не отсортирован по дате — новое обращение почти никогда не попадает в первую отрисованную порцию, поэтому список нужно докручивать. Поле поиска по тикетам фильтрует только уже подгруженные строки и не помогает найти ещё не подгруженное обращение, поэтому в тесте не используется.
| Шаг | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Открыть раздел «Техподдержка» | Раздел открывается |
| 2 | Заполнить и отправить форму создания обращения (тема, текст, тип обращения) | Обращение создаётся |
| 3 | Найти созданное обращение через API (для надёжного teardown) | Обращение найдено, известен его id |
| 4 | Дождаться строки с обращением в списке, докручивая список при необходимости | Строка с обращением становится видна |
| 5 | Открыть переписку по обращению | Отправленное сообщение видно в переписке |
