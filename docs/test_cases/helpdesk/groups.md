### TC-HELPDESK_GROUPS-002 Создание группы
- Автотест: tests/api/helpdesk/test_groups_api.py::TestGroupsApi::test_create_group
- Приоритет: high   Тип: api   Роли: admin
- Предусловия: В системе есть пользователи с ролями «Администратор группы» и «Поддержка» (для необязательных полей «Администраторы группы» и «Пользователи»). Пароль IMAP и остальные почтовые реквизиты — заведомо фиктивные, группа удаляется в teardown.
- Требование: Test IT v.2 #9511, правка по docs/helpdesk_recon.md п.4 (#9511 ⚠): форма содержит доп. необязательное мультиполе «Пользователи» между «Префикс группы» и «Email», не описанное в v.2 — учтено в шагах
- Test IT: 3c7cac05-3212-4314-8b23-1bf32d54cc5c
| Шаг | Действие | Ожидаемый результат |
|---|---|---|
| 1 | `POST /admin/group` с CSRF-токеном и обязательными полями: Название, Префикс группы, Email, Пароль IMAP, IMAP Host/Port, Защита соединения IMAP, SMTP Host/Port, Защита соединения SMTP (+ необязательные «Администраторы группы», «Пользователи») | Ответ успешный, группа создана |
| 2 | `GET /admin/group/search` (DataTables) и найти созданную группу по названию | Группа найдена, первой в списке (как при создании через форму) |

### TC-HELPDESK_GROUPS-003 Создание группы через форму
- Автотест: tests/ui/helpdesk/admin/test_groups.py::test_create_group
- Приоритет: high   Тип: ui   Роли: admin
- Предусловия: Пароль IMAP и остальные почтовые реквизиты — заведомо фиктивные, группа удаляется в teardown. Поле «Пароль IMAP» визуально обычный текстовый input (`type="text"`), значение видно открытым текстом — минорная заметка, не блокер.
- Требование: Test IT v.2 #9511, подтверждено docs/helpdesk_recon.md п.4 (#9511 ⚠)
- Test IT: 034021ef-33e0-4569-a6d4-77ad71f376ea
| Шаг | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Открыть «Группы» → кнопка «Добавить группу» | Открывается страница «Добавить группу» |
| 2 | Заполнить обязательные поля (Название, Префикс группы, Email, Пароль IMAP, IMAP Host/Port, Защита соединения IMAP, SMTP Host/Port, Защита соединения SMTP) | Введённые данные отображаются в полях |
| 3 | Нажать «Сохранить и выйти» | Открывается страница «Системные группы», в правом верхнем углу снек-бар, созданная группа — первая в таблице |
