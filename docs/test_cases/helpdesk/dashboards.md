### TC-HELPDESK_DASHBOARDS-003 Фильтры и выгрузка отчёта дашборда
- Статус: ждёт подтверждения владельца функционала (автор кейсов в Test IT v.2)
- Приоритет: low   Тип: ui   Роли: admin
- Предусловия: Состав полей модального окна фильтров собран по DOM без открытия кликом (чтобы не плодить лишние сетевые запросы на уже отрисованные графики) — перепроверить визуально при автоматизации: по v.2 заявлено 7 полей (Группа, Статус, Тег, Тип заявителя, Пользователь, Источник запроса, ХелпРанепа), по DOM найдено 6 (`group_id[]`, `user_id[]`, `status[]`, `request_source[]`, `tags[]`, `direction[]`) без отдельного «Тип заявителя»; `direction[]`, вероятно, соответствует «ХелпРанепа» (docs/helpdesk_recon.md п.4, #9625 ⚠)
- Требование: Test IT v.2 #9625
- Test IT: 7163606b-99d6-4d0f-bb72-3d6f2c941bea
| Шаг | Действие | Ожидаемый результат |
|---|---|---|
| 1 | На любом графике нажать «Фильтры» | Открывается модальное окно с полями-выпадающими списками (перепроверить фактический состав) |
| 2 | Применить фильтр (например, по группе) и нажать «Выгрузить» | Отчёт выгружается в формате XLS или PNG с учётом применённого фильтра |
