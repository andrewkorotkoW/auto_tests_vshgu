### TC-HELPDESK_TICKETS-002 Список тикетов — подгрузка строк таблицы
- Автотест: tests/api/helpdesk/test_tickets_api.py::TestTicketsApi::test_list_tickets
- Приоритет: high   Тип: api   Роли: admin
- Предусловия: В системе есть хотя бы один тикет
- Требование: docs/helpdesk_recon.md п.1 (паттерн `POST /admin/ticket/search`, DataTables)
- Test IT: 42afc67d-5941-4dfc-b321-499761bb4e48
| Шаг | Действие | Ожидаемый результат |
|---|---|---|
| 1 | `POST /admin/ticket/search` (form-urlencoded, стандартные параметры DataTables: `draw`, `columns[...]`, `start`, `length`) с CSRF-токеном из `/admin/ticket` | Ответ 200, JSON `{"draw":N,"recordsTotal":N,"recordsFiltered":N,"data":[...]}`, в `data` есть строки с отрендеренными ячейками |
| 2 | Отфильтровать по известной теме через `search[value]` | `recordsFiltered` уменьшается, в `data` остаются только строки с этой темой |
