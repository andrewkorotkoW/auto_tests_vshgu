Часть 8. Ручной перезапуск синхронизации
Задача
Дать пользователю возможность вручную перезапустить упавшую синхронизацию с МТС Линк из карточки мероприятия.
Зачем
Автоматические ретраи закрывают временные сбои — сеть, таймаут, недоступность МТС Линк. Они не закрывают случаи, где нужно вмешательство человека: истёк или сменился токен интеграции, поменялись настройки в карточке тенанта, пользователь заменил файл на подходящий по формату. После такого исправления нужно запустить синхронизацию сразу, а не ждать следующего автоматического цикла.
Где
В карточке мероприятия, в блоке статусов интеграции (часть 7).
Флоу

1. Кнопка «Повторить» появляется у таблицы со статусами в состоянии ошибки.
2. Нажатие запускает повторную синхронизацию

Повтор создания вебинара
Если упала часть 1 (создание вебинара), остальные части в принципе не могли отработать — им нужен идентификатор вебинара.
Поэтому повтор создания запускает за собой всю цепочку: после успешного создания вебинара автоматически стартуют синхронизация данных, участников, лекторов и файлов
Соотношение с автоматическими ретраями
Ручной запуск не отменяет и не заменяет автоматические ретраи — он даёт возможность не ждать следующей попытки. Если автоматический ретрай уже выполняется, повторный запуск по тому же пункту не создаётся.
Результат
Пользователь исправил причину ошибки и запустил синхронизацию сам
