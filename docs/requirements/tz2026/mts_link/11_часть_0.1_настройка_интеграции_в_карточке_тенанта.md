1 - Часть 0.1 Настройка интеграции с МТС Линк в карточке тенанта понадобится фронт!


Задача 
Добавить в карточку тенанта блок настроек интеграции с МТС Линк, чтобы каждая организация могла подключить свой аккаунт МТС Линк самостоятельно.

Что настраивает пользователь 
Поле	Описание
Токен доступа	Ключ доступа к API аккаунта
Настройки вебинара: в документе проработки Стаса (зашиты на бэке)

https://docs.google.com/document/d/15NM5eV3QzuNPpjTwwN6l6iQsnAlB8W3LgdcXJ-htNWE/edit?tab=t.9ylzhgsu5so8#heading=h.ddjfhjj45vt5

Настройки вебинара применяются ко всем вебинарам, создаваемым этим тенантом.

Как работает сохранение 
Отдельной кнопки «Проверить подключение» нет — проверка встроена в сохранение.

Пользователь вводит данные и нажимает «Сохранить».
Проверяем валидность токена
Если ошибки авторизации нет — валидация пройдена.
После этого сохраняем данные.
Если МТС Линк не ответил или отклонил токен — настройки не сохраняются, пользователю показывается понятная ошибка.

Отображение токена 
Сохранённый токен обратно на фронт не отдаётся — показывается только маска (первые символы и звёздочки).

Правило редактирования: если пользователь не трогал поле токена — сохранённый токен остаётся прежним. Если ввёл новое значение — токен заменяется целиком. Дозаполнения замаскированной части нет.

Результат для фронта 
В данных тенанта появляется признак, что интеграция настроена и проверена. По нему фронт решает, показывать ли тип мероприятия «Вебинар МТС Линк» при создании.

Доступ 
Редактировать настройки может администратор и администратор тенанта.
