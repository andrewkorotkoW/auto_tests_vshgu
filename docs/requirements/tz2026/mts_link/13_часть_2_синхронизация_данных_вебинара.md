Часть 2. Синхронизация данных вебинара (интеграция)


Задача 
При изменении мероприятия типа «МТС Линк» в ЛМС обновить соответствующий вебинар на стороне МТС Линк.

Флоу 
Пользователь редактирует мероприятие и сохраняет его.
Изменения сразу применяются в ЛМС.
Если менялись данные, которые уходят в МТС Линк, — фоном запускается обновление вебинара.
Если менялись только внутренние данные ЛМС — в МТС Линк не обращаемся.
Ограничение по времени 
После начала вебинара редактирование запрещаем на своей стороне: поля мероприятия блокируются, обновление в МТС Линк не отправляется.

Статусы 
Ситуация	Статус
Изменения сохранены, вебинар ещё обновляется	В процессе
Вебинар обновлён	Успешно (зелёная галка)
Обновление не удалось	Ошибка интеграции
При ошибке — пуш пользователю и подсветка статуса в списке мероприятий и календаре.

Поведение при ошибке 
Изменения в ЛМС остаются сохранёнными, не откатываются.
Данные в ЛМС и в МТС Линк расходятся — это отражается статусом ошибки.
Операция повторяется автоматически (ретрай).
Остальные части синхронизации (участники, лекторы, файлы) продолжают работать независимо.
Результат 
Данные вебинара в МТС Линк соответствуют данным мероприятия в ЛМС.
