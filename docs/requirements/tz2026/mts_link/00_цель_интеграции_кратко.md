Интеграция с МТС линк
Цель интеграции АСУО с МТС Линк — проводить вебинары на платформе МТС Линк, управляя ими из АСУО: вебинар создаётся из карточки очного мероприятия, проводится в МТС Линк, а данные о посещении и запись возвращаются в АСУО для учёта в учебном процессе.
По бизнес-потребностям ТЗ (4.1.1):

* автоматическое создание вебинара на основе расписания из АСУО;
* бесшовный переход обучающегося из АСУО в МТС Линк;
* хранение записи вебинара в АСУО;
* хранение статистики по вебинару в АСУО (со связью с учебными планами).
