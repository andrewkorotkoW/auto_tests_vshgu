Часть 5. Синхронизация файлов презентаций


Задача 
Поддерживать набор презентаций вебинара в МТС Линк в соответствии с файлами, прикреплёнными к мероприятию в ЛМС.

Контекст 
Файлы хранятся в ЛМС. Чтобы они были доступны ведущему во время вебинара, их нужно загрузить в хранилище МТС Линк и привязать к вебинару. Это самая долгая часть синхронизации — большие файлы грузятся минутами.

Флоу 
Работает как сверка: сравниваем файлы мероприятия в ЛМС с файлами, привязанными к вебинару в МТС Линк, и добиваем разницу. Обрабатываем по одному файлу за раз.

Файл добавили — загружаем в хранилище МТС Линк, полученный идентификатор привязываем к вебинару. Сохраняем связь у себя.
Файл заменили — загружаем новый и привязываем, старый отвязываем от вебинара.
Файл удалили — отвязываем от вебинара в МТС Линк.
Запускается при создании вебинара и при любом изменении состава файлов мероприятия.

Ограничения по файлам 
Форматы и максимальный размер — по ограничениям МТС Линк (документация).

Проверяем файл на своей стороне до отправки. Если файл не проходит по формату или размеру — не отправляем его в МТС Линк, показываем пользователю понятную ошибку с указанием, какой именно файл не подошёл и почему. Остальные файлы при этом загружаются.

Статусы 
Ситуация	Статус
Файлы ещё загружаются	В процессе
Все файлы загружены и привязаны	Успешно (зелёная галка)
Часть файлов не удалось загрузить	Ошибка интеграции
При ошибке — пуш пользователю и подсветка статуса в списке мероприятий и календаре.

Поведение при ошибке 
Успешно загруженные файлы остаются привязанными — откат не делаем.
Операция повторяется автоматически: следующий прогон доделает файлы, которые не прошли.
Ошибка по одному файлу не блокирует загрузку остальных.
Не блокирует регистрацию слушателей и назначение лекторов.
Результат 
Все презентации мероприятия загружены в МТС Линк и привязаны к вебинару, ведущий видит их при проведении.
