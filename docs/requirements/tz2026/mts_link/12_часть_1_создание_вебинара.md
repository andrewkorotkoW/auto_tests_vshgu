Часть 1. Создание вебинара в МТС Линк (Интеграция)


Задача 
При создании очного мероприятия типа «МТС Линк» создать соответствующий вебинар на стороне МТС Линк.

Контекст 
Тип мероприятия «МТС Линк» доступен только тем тенантам, у которых настроена и проверена интеграция. Настройки вебинара по умолчанию берутся с бэка, остальные данные — из самого мероприятия.

Флоу 
Пользователь создаёт мероприятие типа «МТС Линк» и сохраняет его.
Мероприятие сразу создаётся в ЛМС — ждать МТС Линк пользователь не должен.
Фоном запускается создание вебинара:
создаётся сессия (одна сессия на один вебинар);
создаётся вебинар в этой сессии.
Из ответа МТС Линк сохраняем идентификаторы вебинара и сессии, а также ссылку на вебинар.
Ссылка подставляется в поле URL мероприятия — вручную его заполнить нельзя.
Статусы 
Ситуация	Статус
Мероприятие создано, вебинар ещё создаётся	В процессе
Вебинар создан	Успешно (зелёная галка)
Создание не удалось	Ошибка интеграции
При ошибке пользователю уходит пуш, в списке мероприятий и в календаре мероприятие подсвечивается статусом ошибки. Детали статусов и уведомлений — в части 7.

Поведение при ошибке 
Мероприятие в ЛМС остаётся созданным, не удаляется.
Ссылки на вебинар нет, поле URL пустое.
Операция повторяется автоматически (ретрай).
Части 2–5 не запускаются, пока вебинар не создан — им нужен его идентификатор.
Результат 
Мероприятие в ЛМС связано с вебинаром в МТС Линк: сохранены идентификаторы вебинара и сессии, а также ссылка для входа. Остальные части синхронизации могут начинать работу.
