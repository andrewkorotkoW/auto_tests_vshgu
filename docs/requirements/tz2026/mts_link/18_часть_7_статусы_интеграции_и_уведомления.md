Часть 7. Статусы интеграции и уведомления


Задача 
Показывать пользователю состояние интеграции с МТС Линк по каждому мероприятию и уведомлять об ошибках.

Сквозная часть: все остальные части (1–6) пишут свой результат сюда, а отображением и уведомлением занимается только она.

Зачем 
Вся работа с МТС Линк идёт асинхронно — пользователь сохранил мероприятие и ушёл. Без явных статусов он не узнает, что вебинар не создался, слушатели не зарегистрировались или презентация не загрузилась. Обнаружит только в момент проведения, когда чинить уже поздно.

Состояния 
Состояние	Когда
В процессе	Хотя бы одна операция синхронизации ещё выполняется
Успешно	Все операции завершились успешно
Ошибка интеграции	Хотя бы одна операция завершилась ошибкой
Итоговое состояние мероприятия — сводное по всем частям: ошибка в любой из них даёт статус ошибки на мероприятии целиком.

Где показываем 
Список мероприятий и карточка 
Индикатор состояния у каждого мероприятия типа «МТС Линк»:

Успешно — зелёная галка.
Ошибка интеграции — подсветка мероприятия и иконка ошибки.
В процессе — индикатор выполнения.
По индикатору сразу видно, какие мероприятия требуют внимания, без открытия каждого.

Карточка мероприятия 
Детализация по каждой части отдельно:

Что	Состояние
Создание вебинара	Успешно / в процессе / ошибка
Данные вебинара	Успешно / в процессе / ошибка
Участники	Успешно / в процессе / ошибка
Лекторы	Успешно / в процессе / ошибка
Файлы презентаций	Успешно / в процессе / ошибка
Уведомления 
При переходе любой части в состояние ошибки — пуш пользователю, создавшему мероприятие. Переход на карточку мероприятия.

Пуш отправляется один раз на факт ошибки, а не на каждую попытку ретрая.

Результат 
Пользователь видит состояние интеграции прямо в списке и календаре
