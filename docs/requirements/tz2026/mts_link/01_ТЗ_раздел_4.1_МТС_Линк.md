1. ТЗ


Кратко 
Нужно научить Систему создавать вебинары в МТС Линк из карточки мероприятия, автоматически пускать туда пользователей по их роли с бесшовным переходом, а после вебинара забирать обратно запись и статистику посещений и связывать её с учебными планами.

4.1 Требования к интеграции Системы с платформой «МТС Линк» 
4.1.1 Бизнес-потребность

4.1.1.1 Возможность автоматического создания вебинара на основании расписания, созданного в Системе.

4.1.1.2 Возможность бесшовного перехода обучающегося из Системы в МТС Линк.

4.1.1.3 Возможность хранения записи вебинара в Системе.

4.1.1.4 Возможность хранения статистики по вебинару в Системе.

4.1.2 Общие требования

4.1.2.1 Интеграция Системы с платформой «МТС Линк» должна заключаться в возможности передачи (и, при необходимости, синхронизации) между Системой и платформой «МТС Линк» следующих типов сущностей:

- информации об очном мероприятии типа «Вебинар» (в том числе, должна быть возможность создавать вебинары на платформе «МТС Линк»);

- УЗ пользователей (в том числе, должна быть возможность вести статистику по взаимодействию с вебинарами);

- Записи вебинара;

4.1.2.2 Синхронизация УЗ пользователей должна осуществляться в автоматическом режиме.

4.1.2.3 В ходе синхронизации УЗ пользователей должны быть определены алгоритмы действий в следующих ситуациях:

- сущность присутствует на платформе «МТС Линк» и отсутствует в Системе;

- сущность отсутствует на платформе «МТС Линк» и присутствует в Системе;

- сущность присутствует и на платформе «МТС Линк», и в Системе, при этом часть атрибутов сущности различается (в данной ситуации должно быть определено какие данные считать приоритетными).

4.1.2.4 В рамках работ не предполагается адаптация методов платформы «МТС Линк», планируется использование готовых решений: https://help.mts-link.ru/category/4157.

4.1.2.5 Должна быть обеспечена связь получаемой статистики с функционалом учебных планов в Системе.

4.1.3 Переход из Системы на платформу «МТС Линк»

4.1.3.1 В интерфейсы Системы должны быть добавлены элементы для возможности перехода из Системы на платформу «МТС Линк».

4.1.3.2 Синхронизированные пользователи должны иметь возможность бесшовного перехода (например, с помощью SSO) между Системой и платформой «МТС Линк». При этом, возможные действия на платформе «МТС Линк» должны определяться ролью пользователя в Системе.

4.1.4 Ролевая модель

4.1.4.1 При необходимости в Системе должны быть доработаны имеющиеся роли для разграничения доступа к данным, формируемым и/или модифицируемым в ходе взаимодействия Системы и платформы «МТС Линк», в части доступных действий:

- просмотр;

- совершение действий:

- добавление;

- изменение;

- удаление.

4.1.5 Требования к журналированию действий

4.1.5.1 Должен быть определен перечень действий, которые должны журналироваться.
