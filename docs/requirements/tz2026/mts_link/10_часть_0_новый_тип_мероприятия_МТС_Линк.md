Часть 0. Новый тип мероприятия «Вебинар МТС Линк» понадобится фронт!
Задача
Добавить новый тип мероприятия «МТС Линк»
Видимость типа

* Если у тенанта настроена и проверена интеграция с МТС Линк — при создании мероприятия в админке появляется иконка нового типа «МТС Линк».
* Если интеграции нет или она не проверена — иконка скрыта.

Признак наличия интеграции приходит с бэка в данных тенанта
Форма создания
Набор полей тот же, что у обычного мероприятия, с одним отличием:

* URL мероприятия недоступен для заполнения — ссылка приходит от МТС Линк после создания вебинара и подставляется автоматически.

Тип мероприятия
Тип фиксируется при создании и в дальнейшем не меняется — ни на «МТС Линк», ни с него.
Статусы в результатах активности
В результатах активности отображаются статусы по мероприятию:

* статус создания вебинара в МТС Линк;
* статус конвертации записи вебинара.

Если интеграцию отключили
Уже созданные мероприятия типа «МТС Линк» остаются доступными и продолжают работать как раньше. Скрывается только возможность создавать новые.
