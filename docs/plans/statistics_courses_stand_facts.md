# Статистика обучения → Курсы: факты со стенда (24.09.2026, от владельца)

Страница живёт в **глобальной админке**: `https://global-develop.d2.devspark.ru/admin/learning-statistics/courses/<course_id>/info`
(не portal-develop; в .env это DEVELOP_GLOBAL_URL). Список курсов: `/admin/learning-statistics/courses`.
Примеры: SCORM-курс id=11, TinCan-курс id=294 — на обоих «Данные отсутствуют» (слушателей нет), верхние блоки
(карта слева, диаграммы справа) на скринах пустые серые — данных нет или не загрузились; проверять с назначенными слушателями.
