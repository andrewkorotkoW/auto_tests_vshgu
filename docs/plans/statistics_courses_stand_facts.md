# Статистика обучения → Курсы: факты со стенда (24.09.2026, от владельца)

Страница живёт в **глобальной админке**: `https://global-develop.d2.devspark.ru/admin/learning-statistics/courses/<course_id>/info`
(не portal-develop; в .env это DEVELOP_GLOBAL_URL). Список курсов: `/admin/learning-statistics/courses`.
Примеры: SCORM-курс id=11, TinCan-курс id=294 — на обоих «Данные отсутствуют» (слушателей нет), верхние блоки
(карта слева, диаграммы справа) на скринах пустые серые — данных нет или не загрузились; проверять с назначенными слушателями.

## Столбцы таблицы на стенде (фактически, 8 штук)
| # | Столбец |
|---|---|
| 1 | ID |
| 2 | ФИО |
| 3 | Email |
| 4 | Статус курса |
| 5 | Тип назначения |
| 6 | Дата начала обучения по курсу |
| 7 | Дата завершения обучения по курсу |
| 8 | Время прохождения мин |

Над таблицей: кнопка «Выгрузить» (XLS), кнопка обновления, «Фильтр», «Поиск».

## Расхождения ПМИ ↔ стенд (для плана и для вопроса владельцу/разработке)
ПМИ ожидает столбцы «Статус обучения», «Дата завершения последнего пройденного раздела», «Текущий раздел»,
«Прогресс курса», «Время прохождения, мин». На стенде: «Статус курса», «Дата завершения обучения по курсу»,
столбцов «Текущий раздел» и «Прогресс» нет. Шаги ПМИ 18–21 (прогресс по разделам) по текущему стенду проверить
нельзя — либо функционал ещё не выкачен на develop, либо ДТТ 3.2.2 отличается от ПМИ. В плане: тесты на
«Текущий раздел»/«Прогресс» проектировать по ПМИ, но помечать как «ждёт стенда» (xfail/skip с причиной), пока
столбцы не появятся; остальное (статусы, даты начала/завершения, время, тип назначения, выгрузка) — делать сейчас.
