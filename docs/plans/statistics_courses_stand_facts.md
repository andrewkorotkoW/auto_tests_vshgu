# Статистика обучения → Курсы: факты со стенда (24.09.2026, от владельца)

Страница живёт в **глобальной админке**: `https://global-develop.d2.devspark.ru/admin/learning-statistics/courses/<course_id>/info`
(не portal-develop; в .env это DEVELOP_GLOBAL_URL). Список курсов: `/admin/learning-statistics/courses`.
Примеры: SCORM-курс id=11, TinCan-курс id=294 — на обоих «Данные отсутствуют» (слушателей нет), верхние блоки
(карта слева, диаграммы справа) на скринах пустые серые — данных нет или не загрузились; проверять с назначенными слушателями.

скринах пустые серые — слушателей у курсов нет; проверять с назначенными слушателями.

## Выводы для плана
- Шаги ПМИ 18–21 (прогресс по разделам, «Текущий раздел», «Прогресс курса %», «Дата завершения последнего пройденного раздела»)
  проверяются на **TinCan-курсе с несколькими разделами**. Наш `test_data/course_tincan.zip` — это тот же курс, что эталон 4393:
  курс «для Веры))», разделы «Тестирование 1» и «Тестирование 2» (по одному тесту в каждом). Использовать его.
- Владелец: SCORM тоже должен быть в проверках. `test_data/test_lms_scorm_2004.zip` — один SCO (tst_lms), несколько слайдов
  с вопросом Pick One и Results Slide. Для SCORM набор столбцов короткий (без разделов) — проверять шаги 18–21 в упрощённом виде:
  статус «В процессе» после открытия, «Пройдено» после завершения, даты и время; «Текущий раздел» и «Прогресс» для SCORM не ожидать.
- Итого матрица прогонов: TinCan с разделами (полный набор столбцов + блок повторений) и SCORM (короткий набор).
- Для курсов без разделов набор столбцов короче: отдельная проверка «столбцы по типу курса» (8 против 9 + блок повторений).
- Блок «Количество повторений прохождения контента»: после прохождения раздела счётчик раздела растёт — включить в проверки шага 20/21.
- Курс 4393 не трогать и не удалять; тестовые слушатели назначаются на свой курс.
