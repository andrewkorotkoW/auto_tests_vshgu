# ПМИ «Чат с ИИ в курсах» — сценарий проверки (перенос из «Сценарий проверки.docx», 07.10.2026)

Источник — документ владельца «Чат с ИИ_курсы_ПМИ_v2», приложение «Методика испытаний». Ручной прогон по нему
сделан 29.09.2026 на ветке VSHGU2-2375 (`qa_analysis/cases/VSHGU2-2375_AI_chat_PMI_2026-09-29/report.md`);
функциональность с тех пор влита в develop (`is_llm_chat_enabled` у активити, `/content/{id}/llm-chat`).
Блок «Логирование» (pgAdmin, таблицы `entities_logs`, `llm_answers`) в автоматизацию **не входит** — решение
владельца 07.10.2026.

Пометки «факт 29.09» — поведение стенда, подтверждённое владельцем как правильное, когда оно расходится
с текстом ПМИ; автотесты проверяют факт, а не текст ПМИ.
